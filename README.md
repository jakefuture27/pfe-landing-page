# Profit For Everyone ($PFE) - Robinhood Memecoin Landing Page

A responsive, high-energy, clean landing page for the **Profit For Everyone ($PFE)** memecoin on Robinhood.

## Features Included

- **Robinhood Neon Aesthetic**: Built with dark-mode canvas (`#070a0d`), Robinhood green accents (`#00c805`), glowing card borders, and smooth backdrop blur.
- **Official Banner Showcase**: Embeds the official community banner featuring Pepe, Chad Wojak, and the colorful $PFE logo.
- **Direct Twitter / X Integration**: Linked throughout to [@PFEPons](https://x.com/PFEPons).
- **Interactive Robinhood-Style Chart**: HTML5 Canvas graph with interactive timeframe buttons (`1D`, `1W`, `1M`, `1Y`, `ALL`) and hover crosshair with dynamic price/percentage calculation.
- **Prescription Dosage Calculator**: Interactive dollar slider ($50 – $10,000) with multiplier milestones (2x, 5x, 10x, 50x, 100x) and hilarious meme doctor diagnoses.
- **Copy Contract Address**: One-click clipboard copy button with animated toast notification.
- **Tokenomics & Dispensation Guide**: Breakdown of the 1,000,000,000 supply, 0% tax, burned LP, and 3-step buying instructions.
- **Parody & Legal Disclaimers**: Comprehensive disclaimer regarding Pfizer parody and crypto volatility.

## Quick Start / How to Run

You can open the landing page directly in your browser:

```bash
open /Users/zurh/.gemini/antigravity/scratch/pfe-landing-page/index.html
```

Or run a lightweight local server:

```bash
cd /Users/zurh/.gemini/antigravity/scratch/pfe-landing-page
python3 -m http.server 8080
```

Then visit [http://localhost:8080](http://localhost:8080) in any web browser.
